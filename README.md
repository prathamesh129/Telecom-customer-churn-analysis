# Telecom Customer Churn Analysis

## Project Overview

A data analysis project using Python and Power BI to analyze customer churn, identify high-risk customer segments, understand churn patterns, and develop a targeted customer retention strategy.

## Tech Stack

- Python
- Pandas
- Power BI Desktop
- Power Query
- DAX

## Data Source

Dataset: Telecom Customer Churn Dataset.

The dataset contains customer-level telecom information, including customer demographics, tenure, contract type, internet service, payment method, monthly charges, and churn status. It was used to perform churn analysis and build an interactive Power BI dashboard.

## Project Features

- Customer Churn Analysis
- Churn Rate Analysis
- Customer Tenure Analysis
- Contract Analysis
- Internet Service Analysis
- Payment Method Analysis
- Online Security Analysis
- High-Risk Customer Segment Analysis
- Interactive Power BI Dashboard
- Customer Retention Strategy

## Key Insights

- Overall customer churn rate is approximately **26.5%**.
- Month-to-month customers have significantly higher churn.
- Customers in their first year show the highest churn rate.
- Fiber optic customers show a high churn rate.
- Electronic check users have the highest churn among payment methods.
- Customers without Online Security show higher churn.
- A specific combination of high-risk characteristics showed approximately **73% historical churn**.
- A targeted retention strategy was developed based on the analysis.
